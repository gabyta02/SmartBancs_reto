Formato del archivo

Puede ser un .csv o un Excel .xlsx (se lee la primera hoja) con una fila de encabezados. Columnas obligatorias:

ColumnaQué debe contener
id_transaccionIdentificador único (los repetidos se rechazan)
montoNúmero no negativo, p. ej. 100.50 o 100,50
divisaCódigo de moneda, p. ej. USD
fechaFecha válida, p. ej. 2026-09-19 o 19-09-2026
tipoTipo de operación, p. ej. TRANSFERENCIA

Las filas con valores vacíos o inválidos no se cargan y se cuentan como rechazadas.
